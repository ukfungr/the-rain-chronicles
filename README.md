
# Rain Chronicles

A personal creative project exploring the world of **Rain** through pixel art, interactive experiences, storytelling, and web development.

Rain Chronicles is an evolving project. New characters, stories, features, and interactive experiences will be added over time.

## Current Features

### Landing Page

- Minimalist dark background.
- Animated red beam with glowing and pulsing effects.
- Animated **ENTER** link leading to the Universe page.

### Universe

- Interactive radial navigation menu.
- Rain's pixel-art portrait at the center.
- Animated concentric lens segments.
- Four navigation branches: **Story**, **Game**, **World**, and **About**.
- Pixel-inspired typography and animated visual elements.

### Section Pages

The project includes separate pages for:

- **Story** — Explore Rain's story and adventures.
- **Game** — A space for future interactive gameplay.
- **World** — Discover the world and characters of Rain Chronicles.
- **About** — Learn more about the project.

These sections share a collapsible vertical navigation menu.

## Getting Started

### Prerequisites

Install the following tools:

- [Node.js](https://nodejs.org/) (a version supported by your installed Next.js release)
- npm
- Git

### Clone the Repository

```bash
git clone <your-repository-url>
cd <your-project-directory>
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
